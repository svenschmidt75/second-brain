🔧 Knobs you can turn

Set these environment variables (a .env file works too).

SECOND_BRAIN_DIR

📁 Where notes live. Default: ~/second_brain/

LOG_LEVEL

📣 How chatty the stderr log is: TRACE → CRITICAL. Default: INFO

LOG_FILE

🗒️ Debug-level log file, rotates at 50 KB. Default: ~/.local/state/second_brain/app.log

💡 Results go to stdout, log lines go to stderr — so second_brain list | grep idea stays clean.
